# Навыки

Справочник навыков (68). **x2** — навык стоит двойную цену, **множ.** — берётся отдельно под язык/науку/инструмент и т.п.

## Восприятие

| Навык | Name | Стат | x2 | Множ. | Описание |
|---|---|---|---|---|---|
| Концентрация | Concentration | WILL |  |  | Фокус и ментальный контроль: память, воспоминание деталей, управление собственной физиологией. Мастер просит бросок, когда надо не потерять концентрацию под давлением — вспомнить точную деталь, не дрогнуть под огнём, удержать внимание на задаче. |
| Скрытие/Раскрытие объекта | Conceal/Reveal Object | INT |  |  | Умение прятать предметы и находить спрятанное. Именно этот навык используют, чтобы пронести оружие под одеждой и чтобы заметить у кого-то скрытый ствол. Обычные тайники ищутся именно им, а не Perception. |
| Чтение по губам | Lip Reading | INT |  |  | Чтение по губам: понять, о чём говорят люди, которых вы видите, но не слышите. Пригодится при слежке за переговорами через стекло, с камеры или с другого конца шумного клуба. |
| Внимательность | Perception | INT |  |  | Умение замечать скрытое: улики, ловушки, засады и людей, крадущихся с помощью Stealth. Не работает против предметов, спрятанных навыком Conceal/Reveal Object — для них свой бросок. |
| Выслеживание | Tracking | INT |  |  | Умение идти по следу: читать отпечатки, сломанные ветки и прочие оставленные знаки. Бросок нужен, когда группа преследует беглеца или зверя, и особенно когда цель активно заметает следы. |
